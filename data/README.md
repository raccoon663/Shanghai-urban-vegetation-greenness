# Data

This repository does **not** contain raw or large intermediate remote-sensing data. All scientific results in `outputs/tables/` and `assets/figures/` are derived from the public sources listed below and can be regenerated by acquiring the data and running the pipeline in `scripts/`.

## Why raw data is excluded

- Sentinel-2 and Landsat scene archives, cached tiles, and intermediate raster stacks are large (gigabytes to terabytes) and are already openly distributed by their providers.
- Storing them on GitHub would duplicate public archives and is against the intended use of the platform.
- The repository is therefore a *code + results* snapshot; raw inputs remain reproducible from the original sources with the configuration in `config/final_analysis.json`.

## Acquisition notes

- Analysis CRS: EPSG:32651 (UTM 51N); display CRS: EPSG:4326.
- Built fraction is computed within 1,000 m (primary) and 90 m (sensitivity) of each patch centroid.
- Temporal QC (predefined before endpoint extraction): ≥15 valid observations per patch-year, ≥3 valid July–August observations, maximum March–November gap ≤45 days; only real observations are used (no fabricated interpolation).
- Landsat is cross-calibrated to Sentinel-2 and used only as calibration support under the predefined sensor strategies (see `docs/methods.md`).

To reproduce, acquire the above collections for the Shanghai AOI over 2017–2025, place them under the expected `data/` layout, and run the scripts referenced in `docs/methods.md`.
